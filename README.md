# sky_django_course
## Описание
Проект по созданию интернет-магазина с использованием фреймворка django.
В папке config находятся файлы настроек проекта.
В папке static находятся файлы со стилями для файлов с html-шаблоном.
Папка catalog - приложение.
## Установка:
Клонирование с удаленного репозитория:
```
git clone https://github.com/mikhailsorochinskiy/sky_django_course.git
```
### Установка зависимостей:
Для пользователя:
```
poetry install --no--dev
```
Для разработчика:
```
poetry install
```

## Пример использования:
В командной строке выполните команду.
```
python manage.py runserver
```
